# 抽取精确率与召回率基线

执行 `python -m pipeline.supervision.extraction_benchmark --output <新结果.json>`，使用实际配置网关、prepare_extraction 与覆盖检查。`--no-coverage` 可运行单轮基线。默认18份模拟IR、27条标准记录；`--suite basic` 为12份19条，`--suite challenge` 为6份8条。基础集覆盖九类报告模块以及背景信息、资料缺失、历史整改三类边界；复杂集覆盖同单位多事项、同案多月、自然语言问题、分散整改信息、实际金额与预算区分、制度要求不能当作实际问题。每份样例使用一个关键字段的独立简化规则；不是全字段生产规则、真实PDF、OCR、向量候选召回或Java全链路评测。

标准答案由固定样例预先定义，包含事项锚点、单位、记录类型和字段值；不把gold/期望数量传给模型，不用模型给自己打分。输出逐案例预测、标准答案、证据、错漏索引和汇总，模型失败也记录，不能跳过失败案例只汇报成功样本。

## 口径

- 事项TP：预测引用的原文包含对应事项锚点，单位和记录性质正确，并与标准记录一对一匹配。仅意味着事项被识别到；描述是否忠实由字段指标及后续核验另行评价。
- FP：未匹配的预测，包括重复、错单位、错类型和额外事项。
- FN：未被预测匹配的标准记录，包括模型调用失败导致未交付的记录。
- 精确率 = TP / (TP + FP)；召回率 = TP / (TP + FN)；F1 = 2TP / (2TP + FP + FN)。分母为0返回null，不伪装100%。汇总采用微平均，即先累加TP/FP/FN。
- 字段指标：在一对一匹配的事项上，字段key及去除首尾空白后的value必须与标准答案相等。错误值同时产生一个FP和一个FN，未匹配事项的所有字段计FP。这里是严格字符串指标，同义改写也可能不命中，不等于语义错误。
- 另报normalizedFields：仅忽略首尾空白及末尾中文句号/分号，保留严格指标。该补充口径在首次试跑观察到句末标点差异后增加，不能称为预注册指标；不处理同义词，不删除否定词、数字或金额小数点。
- 先最大化事项匹配数，再最大化正确字段数，避免重复预测排序改变字段评分。每个样例标准事项最多16条，防止匹配状态爆炸。
- 无事项样例单独检查是否多抽，并报告failedCases；失败的负样例不作为“正确拒抽”成功证据。

## 使用限制

这是一组较容易、字段显式的合成回归基线，用于捕捉明显回退，不能用它宣称生产精确率/召回率达到某水平。真实长文、多页事实、同单位多事项、复杂表格和扫描件需要另外制作人工逐项标注集并复核锚点映射；不把人工未核对的模型输出当标准答案。

评分器单测：`pytest pipeline/tests/test_supervision_extraction_benchmark.py`。包含重复预测、字段错误、单位/类型错误、零分母及预测顺序稳定性。
